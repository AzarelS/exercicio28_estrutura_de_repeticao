# Lista de Exercícios: Estruturas de Repetição em Java

Repositório acadêmico destinado ao armazenamento e organização de exercícios práticos desenvolvidos para a disciplina de programação em Java da **UNISUL**, sob a supervisão do professor **Osmar**.

O objetivo deste projeto é consolidar o aprendizado sobre **estruturas de repetição**, aplicando conceitos fundamentais de controle de fluxo para executar blocos de código de forma repetitiva e eficiente na linguagem Java.

## Tecnologias e Requisitos

- **Linguagem:** Java (JDK 11 ou superior)
- **Ambiente de Desenvolvimento:** Qualquer IDE compatível com Java (Eclipse, IntelliJ IDEA, NetBeans) ou editor de texto com terminal.

## Tópicos Abordados

Os algoritmos presentes neste diretório cobrem os seguintes conceitos de estruturas de repetição:

- Estrutura de repetição com teste no início (`while`)
- Estrutura de repetição com teste no final (`do-while`)
- Estrutura de repetição com quantidade definida de iterações (`for`)
- Utilização de contadores e acumuladores
- Controle de fluxo dentro de estruturas de repetição
- Utilização de `break` e `continue`
- Estruturas de repetição aninhadas
- Aplicação de operadores relacionais e lógicos em condições de repetição

## Instruções de Compilação e Execução

Para executar os códigos através da linha de comando, siga os passos abaixo:

1. Abra o terminal no diretório onde o arquivo `.java` está localizado.

2. Compile o código-fonte utilizando o comando:

javac exercicio.java
